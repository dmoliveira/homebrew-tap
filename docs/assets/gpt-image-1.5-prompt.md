# GPT Image 1.5 Prompt For README Hero

Use this prompt with GPT Image 1.5 if you want to replace the SVG hero with a
generated PNG/WebP asset.

## Prompt

Create a clean, modern GitHub README hero image for a project called
"Homebrew Tap". The scene should show a stylized beer tap pouring glowing amber
liquid into a glass made of terminal code. Include subtle command-line motifs
like `brew tap dmoliveira/tap` and `brew install sk` in the background. Style:
minimal vector illustration, high contrast, friendly dev vibe, dark teal and
amber palette, no logos of third-party brands, no copyrighted characters, no
photorealism. Include text title "Homebrew Tap" and subtitle "Fast installs for
