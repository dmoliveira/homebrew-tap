# Homebrew Tap Wiki Home

Use this page as starter content for the GitHub Wiki home page.

## What This Tap Provides

`dmoliveira/tap` is a Homebrew tap for custom command-line tools that are
maintained outside Homebrew core.

## Quick Install

```bash
brew tap dmoliveira/tap
brew install sk
```

## Formulae

- `sk`
- `loopmux`
- `opencode-tmux-mem`
